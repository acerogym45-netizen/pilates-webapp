CHAPTER 01 시스템 개요 무엇을 위한 시스템인가

시스템이 하는 일

📋 수강 신청 접수
입주민이 QR코드·링크로 직접 신청서를 작성·서명. 담당자가 별도로 접수를 받지 않아도 됩니다.
🚪 해지 신청 접수
입주민이 직접 온라인으로 해지 신청. 접수 즉시 자동 승인됩니다.
📊 정산 리포트
매월 수강생 명단·수강료 합계를 엑셀로 자동 생성합니다.
📣 공지사항
입주민 페이지에 표시되는 공지사항을 관리자가 직접 작성·수정합니다.
💬 문의 응답
입주민이 온라인으로 문의 등록 → 관리자가 답변 → 문자(SMS) 자동 발송.
📅 출석부
프로그램별 출석부를 PDF로 출력합니다.

페이지 구분

페이지주소사용 주체주요 기능
입주민 페이지 apt-webapp.vercel.app 입주민 수강 신청, 해지 신청, 문의, 공지 열람
관리자 페이지 apt-webapp.vercel.app/admin 담당자(실무자) 신청 현황 조회, 정산 출력, 공지 작성, 문의 답변 등
✅ 핵심 원칙
수강 신청·해지 신청은 모두 온라인(시스템)으로만 처리합니다.
전화·구두·문자로 받은 요청은 효력이 없으며, 반드시 입주민이 직접 온라인으로 신청하도록 안내해야 합니다.
CHAPTER 02 관리자 페이지 접속 및 메뉴 구성

접속 방법

  1. 브라우저 주소창에 apt-webapp.vercel.app/admin 입력
  2. 로그인 화면에서 단지 코드 또는 마스터 비밀번호 입력
  3. 로그인 완료 → 대시보드 화면 진입
🔑 단지 로그인 (일반 담당자)

단지별로 발급된 단지 코드로 로그인합니다.
해당 단지의 데이터만 조회·관리할 수 있습니다.
🔑 마스터 로그인 (총괄 관리자)

마스터 비밀번호로 로그인합니다.
전체 단지 데이터를 조회하고 단지를 추가·삭제할 수 있습니다.

🚫 기간 외 접수 불가
시스템이 접수 기간 외에는 신청 자체를 차단합니다. 입주민이 기간 외에 신청하려 하면 안내 메시지가 표시됩니다.
담당자도 기간 외 온라인 접수를 받아서는 안 됩니다.

자동 연장 원칙

해지 신청을 하지 않으면 수강이 자동 연장됩니다. 매월 22~26일 사이에 해지 신청을 완료하지 않으면 다음 달 수강료가 자동으로 청구됩니다. 입주민에게 이 점을 명확히 안내해야 합니다.

해지 신청 처리 원칙

  • 입주민이 온라인으로 해지 신청 → 즉시 자동 승인 (담당자 개입 불필요)
  • 해지 신청 후 번복 불가 — 재수강을 원하면 다음 접수 기간에 다시 신청
  • 해지 신청은 반드시 온라인으로만 처리 — 전화·구두 요청 불인정
  • 당월은 정상 수강하고 익월부터 해지 적용

환불 정책

원칙: 환불은 예외적 사유에만 가능

환불 가능 사유 — 천재지변, 질병, 부상 등 불가피한 사유
환불 불가 사유 — 단순 변심, 취업, 이직, 출장, 여행, 강사 교체, 수업 구성원 변경 등

환불금 계산 방식
환불금 = 원금 - 위약금(원금의 10%) - 진행 횟수분 수강료

예) 원금 180,000원, 총 8회 중 3회 진행 시
→ 위약금 18,000원 + 진행분 67,500원(=180,000÷8×3) 차감 → 환불액 94,500원

프로그램 자동 활성화/비활성화

매일 자정(KST 09:00) 시스템이 자동으로 프로그램 활성화 여부를 판단합니다.
접수 기간(22~26일)에는 자동으로 활성화 → 입주민이 신청 가능
비접수 기간에는 자동으로 비활성화 → 신규 신청 차단

수동 제어도 가능 — 프로그램 관리 탭 하단의 "자동 스케줄 상태" 패널에서
담당자가 직접 수동으로 활성화/비활성화할 수 있습니다. (마스터 비밀번호 필요)

CHAPTER 05 신청 관리 수강 신청 처리 및 현황 확인

신청 상태 종류

상태의미담당자 조치

대기 정원이 차서 대기 중인 회원 자리 생기면 수동 승인 처리

신청 승인 방법

  1. 신청 관리 메뉴 클릭
  2. 상단 필터에서 "대기" 선택 → 대기 중인 신청 목록 확인
  3. 신청자 이름 클릭 → 상세 정보 확인 (동·호수, 프로그램, 서명 등)
  4. "승인" 버튼 클릭 → 완료

신청 정보 수정 방법

  1. 신청자 상세 화면에서 "수정" 버튼 클릭
  2. 프로그램·시간대·연락처 등 수정 가능
  3. "저장" 버튼 클릭
⚠️ 정원 초과 시
해당 시간대 정원이 이미 가득 찬 경우, 시스템이 신청을 자동으로 차단합니다.
(기존 대기 시스템은 폐지됨 — 정원 마감 시 신규 대기 등록 불가)
입주민에게 다른 시간대를 선택하거나 다음 달 재신청을 안내하세요.

✅ 자동 처리 — 해지 신청은 접수 즉시 시스템이 자동으로 승인 처리합니다.

해지 관리 탭 구성

탭내용
해지 신청 입주민이 신청한 해지 목록 (자동 승인된 내역 포함)
환불 신청 환불을 요청한 건 목록 — 담당자가 직접 검토 후 처리

해지자 일괄 등록

엑셀로 여러 명의 해지를 한 번에 등록해야 할 경우(예: 이전 데이터 마이그레이션, 오프라인 해지 일괄 반영) 해지 관리 탭의 "일괄 등록" 기능을 사용합니다.

  1. 해지 관리 → "일괄 등록" 버튼 클릭
  2. 양식 파일 다운로드 (동·호수·이름·전화번호·프로그램명·해지월 입력)
  3. 작성된 엑셀 업로드 → 미리보기 확인 → 등록

환불 처리 절차

  1. 해지 관리 → "환불 신청" 탭에서 해당 건 클릭
  2. 환불 사유 확인 (불가피한 사유인지 검토)
  3. 환불금 계산: 원금 - 위약금(10%) - 진행 횟수분
  4. 환불 처리 후 상태를 "승인"으로 변경
⚠️ 해지 신청 번복 불가
자동 승인된 해지는 취소할 수 없습니다. 재수강을 원하는 입주민은 다음 접수 기간(22~26일)에 새로 신청해야 합니다.

CHAPTER 09 월별 정산 리포트 엑셀 3시트 출력

정산 리포트 출력 방법

  1. 정산 리포트 메뉴 클릭
  2. 조회 월 선택 (예: 2026-05)
  3. "조회" 버튼 클릭 → 화면에 요약 표시
  4. "엑셀 다운로드 (3시트)" 버튼 클릭

엑셀 파일 구성 (3시트)

시트내용주 용도
① 정산 내역 당월 수강생 전체 목록 + 수강료 + 신규 입회자 섹션 수강료 수납 확인, 회계 제출
② 동호수계 세대별 최종 부과금액 합산 관리비 청구 연동 자료
③ 수강신청 내역 다음 달 수강 예정자 전체 목록 익월 수업 준비, 강사 전달용

정산 리포트 조회 후 하단의 "월별 수업횟수 설정" 패널에서 당월·차월 프로그램별 실제 수업 횟수를 입력할 수 있습니다.
공휴일 등으로 실제 수업 횟수가 다를 경우 여기서 조정합니다.

해지자 일괄 등록 (정산 탭)

정산 리포트 탭에서도 해지자를 엑셀로 일괄 등록할 수 있습니다. "일괄 등록" 버튼을 통해 해지자 명단을 업로드하면 해지 관리 탭에 자동 반영됩니다.

⚠️ 정산 시점 주의
정산 리포트는 조회 시점 기준으로 데이터를 가져옵니다.

CHAPTER 12 자주 묻는 질문 (FAQ)

입주민으로부터 자주 받는 질문

Q. 신청하고 싶은데 신청 버튼이 안 보여요

A. 현재 접수 기간이 아닙니다.
신규 등록·해지 신청은 매월 22일 09시 ~ 26일 09시에만 가능합니다.
다음 접수 기간에 신청해 주시도록 안내하세요.

Q. 해지 신청을 했는데 이번 달에도 수업을 들어도 되나요?

A. 네, 됩니다. 해지 신청 후에도 당월은 정상 수강하고 익월부터 해지가 적용됩니다.

Q. 해지 신청을 취소하고 싶어요

A. 번복이 불가합니다.
재수강을 원하시면 다음 접수 기간(22~26일)에 다시 신청해 주셔야 합니다.

Q. 시간대를 바꾸고 싶어요

A. 매월 20~27일 사이에 입주민 페이지에서 직접 변경할 수 있습니다.
단, 변경하려는 시간대에 정원 여유가 있어야 합니다.

Q. 환불이 되나요?

A. 원칙적으로 환불은 불가합니다.
단, 천재지변·질병·부상 등 불가피한 사유에 한해 예외적으로 검토됩니다.
환불 시에는 위약금(원금의 10%) + 진행 횟수분 차감 후 잔여 금액을 지급합니다.
단순 변심, 취업, 이직, 출장, 여행 등은 환불 대상이 아닙니다.

Q. 정원이 마감되었다고 뜨는데 대기 등록이 안 되나요?

A. 현재 대기 시스템은 운영하지 않습니다.
정원이 찬 시간대는 신청이 불가하며, 다른 시간대를 선택하거나 다음 달 재신청을 안내하세요.

담당자가 자주 하는 실수

실수 유형올바른 처리 방법
전화로 해지 접수를 받음 전화 해지는 효력 없음. 입주민이 직접 온라인으로 신청하도록 안내
정산 리포트를 접수 기간 중에 출력 접수 마감(26일 09시) 이후, 해지 처리 완료 후에 출력
